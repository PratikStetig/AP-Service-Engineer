General Practice for the Recommended Coating System

After assessing rusting, blistering, and other coating failures, the following recommendations are made:

9.1 General Surface Preparation*
  • Ensure relative humidity near the job structure is below 80%.
  • Remove temporary weld supports and spatter before preparation.
  • Perform solvent cleaning (SSPC SP-1) using Thinner - T131.
  • Remove loose paint and rust using power tools.
  • Hand tool cleaning is permissible in areas with limited access.
  • Use low-pressure water jetting to remove contaminants.

Refer to the technical data sheet for more detailed instructions.

Stripe Coats:

Apply a stripe coat to weak areas like edges, bolts, and corners using high-quality brushes.
